# Как править сайт «Лёгкий код»

Инструкция для Френка и Эрика. Код, цвета и анимации здесь не меняются.

## Куда заходить

Редактор: https://app.pagescms.org/

Войти нужно через GitHub того человека, которому открыли репозиторий сайта. После входа выбрать репозиторий «Лёгкий код» и ветку `main`.

Репозиторий уже подключён к редактору.

## Что можно менять

Слева такие разделы:

- **Настройки сайта.** Название, логотип, телефоны, почта, адреса, мессенджеры, текст подвала.
- **Главная страница.** Заголовок первого экрана, кнопки, тексты секций, проблемы, преимущества, финальный призыв.
- **Услуги.** Карточка на главной и текст посадочной страницы. Адрес страницы лучше не менять у уже опубликованной услуги.
- **Тарифы.** Название, описание, состав, пакеты часов, порядок. Цену можно оставить пустой.
- **Кейсы.** Добавить, поправить или скрыть. Чтобы скрыть, снимите «Показывать».
- **FAQ.** Вопрос, ответ и порядок.
- **Документы.** Политика, согласие и cookies. Эти страницы удалить нельзя.

SEO Title и SEO Description правятся у главной и у каждой услуги. Это заголовок и описание в поиске.

Картинки загружаются кнопкой изображения. Они попадают в папку сайта, отдельно ничего выкладывать не нужно.

## Как сохранить

1. Откройте раздел.
2. Измените текст.
3. Нажмите сохранение. Pages CMS сам отправит изменение в GitHub.
4. Подождите, пока в GitHub во вкладке Actions закончится «Тестовая сборка». Зелёная галочка значит, что сайт собрался и тестовая версия обновилась.
5. Тестовый адрес: https://tverdokhlebalex.github.io/1clekod/ Обновление занимает минуту-две после зелёной галочки. Боевой сайт 1clekod.ru от этой правки не меняется.

Пустое обязательное поле сохранить нельзя. Если страница не сохраняется, посмотрите поле с пометкой обязательного.

## Чего не делать

- Не удаляйте главную, настройки, тарифы, FAQ и документы. Эти разделы от удаления закрыты.
- Не удаляйте услугу. Если она больше не нужна, снимите «Показывать на сайте» и «Показывать на главной».
- Не меняйте адрес уже работающей услуги. Иначе старые ссылки перестанут открываться.
- Не включайте старые адреса в разделе «Старые адреса. Не для ежедневной правки» без разработчика.
- Не вставляйте токены, пароли и коды Telegram. Их в редакторе нет специально.

## Что уже подключено

Репозиторий GitHub подключён, Pages CMS сохраняет правки в ветку `main`. После сохранения запускается «Тестовая сборка», и тестовый сайт обновляется сам.

Боевой сайт на 1clekod.ru из этой сборки не обновляется. Чтобы Френк или Эрик могли сохранять тексты, у них должно быть право записи в репозиторий.
